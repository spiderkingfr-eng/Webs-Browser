What's new in this version

    Questions

    Is it really free?

    Yes. The browser, the VPN, the games and Web AI are all free. There are no ads (it blocks them, after all) and you don't need an account.

    Is Web AI free too?

    Yes, with a daily limit for each device so it stays free for everyone. The number of questions you have left today shows at the top of Web AI.

    What happens to what I ask Web AI?

    Your question, and the page text when you ask about a page, are sent to Web AI's server to be answered by Claude, Anthropic's AI. Your conversation is kept on your device. Everything else, like your history, bookmarks and settings, stays on your computer or phone.

    Which one should I download, the installer or the zip?

    The installer. It's tiny, installs Webs for you, and keeps it up to date by itself. The zip is the same browser as a single file you can run from anywhere, like a USB stick.

    What do I need?

    Windows 10 or 11. Webs uses the Microsoft Edge WebView2 engine that's already part of Windows, so sites work just like they do in Edge or Chrome, and security fixes arrive with Windows Update. For the phone app, any iPhone with Safari.

    Is there a Mac version?

    Not yet. Webs is for Windows and iPhone for now.
